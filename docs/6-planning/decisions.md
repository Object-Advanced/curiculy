# Decision log

Product and technical decisions, newest first. Each says what was decided, why, and what it affects. Revisit a decision only on purpose.

| 2026-10-12 | **The Library's kinds are Book, Textbook, Workbook and Online site,** and the page is called **Library** (not "Curriculum catalog"). **The lesson list lives on the textbook;** workbooks, readers and teacher's editions are their own library items ("materials" are dropped). Adding is a **step-by-step pop-up walkthrough**: basics first, then "What is this?", then only that kind's questions, each explained in plain words. | The old name hid what the page holds; one record per physical book is simpler to enter, share and reuse | [Product spine](product-spine.md#library-one-shelf-four-kinds-of-book) |

| 2026-10-12 | **Curricula other families built are suggested:** a fully built curriculum is contributed automatically; the next family with the same textbook sees each combination families used (with counts) and what's often used with it, and can start from one, adjust it (different novels, same textbook and worktext), or build their own | Reuses whole plans, not just books, without forcing anyone's choices | [Product spine](product-spine.md#curricula-other-families-built) |
