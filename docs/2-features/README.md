# Features: scope and review

Every major function of Curiculy has one page with two halves:
- **Scope:** what it does, who uses it, the screens, the rules, the API, the data and the code.
- **Review (October 2026):** what works well, the problems and risks, the tests, and prioritized recommendations.

**Health** uses three ratings:
- **Solid:** works well; no urgent issues.
- **Works:** fine for the beta; known gaps planned.
- **Needs work:** gets in families' way today.
